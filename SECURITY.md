# Security Policy

## Supported Versions
We actively patch and support security vulnerabilities for the latest major releases of our core package architecture.

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | ✅ Active Support   |
| < v1.0  | ⚠️ Critical Only   |

## Reporting a Vulnerability
**Please do not open public GitHub issues for security vulnerabilities.**

If you discover a potential exploit or security vulnerability within the `pixel-journey` ecosystem, please report it securely by reaching out to the core engineering team directly at:
👉 **security@pixeljourney.io** (or your preferred private contact link)

We aim to acknowledge receipt of your vulnerability report within 48 hours and provide a detailed timeline for remediation and safe deployment.
